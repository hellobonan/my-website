# Hello Bonan

Source for the official bilingual website of **Bonan Zhong (钟博南)**:
[bonan.blog](https://bonan.blog).

The site publishes Bonan's profile and original writing about marketplace and
ecommerce leadership, seller services, artificial intelligence, life science,
travel, and everyday observation in English and Chinese.

## Discovery endpoints

- [XML sitemap](https://bonan.blog/sitemap.xml)
- [RSS feed](https://bonan.blog/feed.xml)
- [AI and LLM guide](https://bonan.blog/llms.txt)
- [Robots policy](https://bonan.blog/robots.txt)

The production site is hosted on Vercel. Its canonical origin is
`https://bonan.blog`; `www.bonan.blog` and the legacy Vercel hostname redirect
or canonicalize to that origin.
